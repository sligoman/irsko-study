# === Projekt: IrskoStudy.cz ===
# Framework: Laravel 12 + Blade + TailwindCSS + Vue 3 (pouze pro reaktivní části)
# Cíl: Moderní, přehledný a přátelský web o studiu v Irsku

# ----------------------------------------------------------
# 1. OBECNÝ KONCEPT
# ----------------------------------------------------------
- Laravel obstará routing, Blade šablony a obsahové stránky.
- Vue se použije pouze pro:
  - Interaktivní části (FAQ, formuláře, dynamický blog)
  - Drobnou reaktivitu (např. načítání obsahu AJAXem)
- Každá stránka má vlastní Blade soubor v `resources/views/pages/`
- Opakující se sekce (header, footer, CTA, reference) jsou jako partials v `resources/views/components/`
- TailwindCSS pro celý layout a styl

Tone of voice:
- Přirozený, osobní, přátelský tón
- Krátké a přehledné texty
- CTA zaměřená na akci: „Domluvte si konzultaci“, „Zjisti víc“, „Začni plánovat studium“

# 2. BRAND DESIGN A BARVY
# ----------------------------------------------------------

## Logo
- Soubor: `/public/images/logo-irsko.png`
- Barva loga: tmavá zelená `#064D45`
- Výška loga v navigaci: 48–56 px
- Použití:
  - Header vlevo nahoře
  - Footer (menší nebo monochromatická varianta)
- Okolo loga nechat minimálně 20 px padding

## Barevná paleta
| Název | HEX kód | Použití |
|--------|----------|----------|
| **Tmavá zelená** | `#064D45` | Primární barva loga, nadpisy, CTA, hlavní prvky |
| **Zelená** | `#5FBA89` | Sekundární barva, hover efekty, ikony |
| **Krémová** | `#F2E6CC` | Pozadí sekcí, boxy, CTA podklady |
| **Bílá** | `#FFFFFF` | Text na tmavém pozadí |
| **Neutrální šedá** | `#f5f5f5` | Podkladové vrstvy, border |

## Typografie
- **Primární font:** `Inter` nebo `Nunito Sans`
- **Sekundární font:** `Open Sans`
- **Barva textu:** `#064D45`
- **Line height:** 1.6–1.8
- Styl komunikace: čistý, moderní, přehledný
